# Sprint 3 — documentos por entregável

Esta pasta reúne, por entregável do enunciado, cópias dos documentos desenvolvidos na Sprint 3, para que cada integrante encontre num só lugar o que produziu e o que vai apresentar. Os originais continuam na pasta `PI2_Sprint3` e no repositório Git, onde o pipeline os gera e os testes os conferem; por isso, esta pasta é uma fotografia de 26/10/2026, refeita por `python montar_pasta_entregas.py` sempre que os originais mudarem. Os links entre documentos foram reescritos para as novas posições, e os que apontam para código levam ao original na pasta `PI2_Sprint3`.
