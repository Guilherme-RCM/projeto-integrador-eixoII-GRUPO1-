## Entregas

As tarefas do PI estão em [entregas/](entregas/), organizadas por módulo. Primeira entrega: [entregas/etl/M5_Tarefa_PI_Semana1_Entrega19out2026.docx](entregas/etl/M5_Tarefa_PI_Semana1_Entrega19out2026.docx) — **19/out/2026**.

### Como entregar (via GitHub)

1. Faça um **fork** deste repositório.
2. Crie a pasta `entregas/equipes/<nome-da-sua-equipe>/` no seu fork.
3. Adicione os arquivos da entrega nessa pasta.
4. Abra um **Pull Request** para este repositório com o título `[Entrega] <equipe> — <tarefa>`.

Dúvidas? Abra uma [Issue](https://github.com/DavidNadlerPrata/projeto-integrador-eixoII/issues).
